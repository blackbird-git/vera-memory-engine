# Publication provenance and exclusion policy

This is a sanitized local candidate exported from private source checkpoint654505c.
It is not the original Vera repository and contains no `.git` directory or remote.
The private repository and its original evidence remain unchanged. No project
license has been selected. File admission is explicit, not a recursive workspace
copy: see PUBLICATION_ALLOWLIST.json and PUBLICATION_MANIFEST.json at the root.

Source Python/tests and admitted fixture bytes are unchanged. Reviewed historical
source is separately copied from9031f10. Documentation was replaced with generic
public-facing guides, and selected evidence was projected through explicit fields.
Original raw artifacts are not presented under their old file paths as if unchanged.
The known path-bearing model-pilot file is excluded altogether.

Each derivative identifies its private source path/revision/SHA256 and transformation.
Those private hashes identify originals; they are NOT checksums of sanitized bytes.
Public output hashes and links are separately recorded and regenerated. No scores,
answers or reviewer judgments were recomputed. Final-answer hashes in reviews
remain bound to unchanged answer text; structural wrappers have different hashes.

Operational timestamps, backup references, server inventories, absolute personal
paths, host names, raw requests/calls, internal generated thinking, process IDs and
per-second memory/disk logs were omitted from exported evidence. Aggregate memory/
GPU capacities and measured inference timings remain research context, not a claim
about the reader's machine. Generic platform paths such as `/proc` and `/mnt/c` in
unchanged research code are intentional dependencies, not personal identifiers.

The prior test log itself is excluded with recovery artifacts; only its documented
122-pass historical fact and original digest appear in evidence/prior-test-status.json.
This is not a new test result. Selected reports preserve failures and limitations
through docs/RESEARCH_RESULTS.md and curated data, rather than copying private
operational diaries. Full original transcripts/reasoning stay outside this export.

PUBLIC_CHECKSUMS.sha256 covers every candidate regular file except itself.
PUBLICATION_MANIFEST.json maps sourced outputs and separately lists newly written
documentation/metadata. The manifest does not hash itself; its integrity is covered
by PUBLIC_CHECKSUMS.sha256. No original private checksum manifest was edited or
copied with stale assertions about excluded files.

Excluded material includes private operational instructions/logs/recovery artifacts,
raw wire transcripts and generated reasoning, pilot metadata containing personal
paths, unused historical drafts/diagnostic outputs, editor workspace state, all
original Git metadata/history/tool refs, ignored personal archives/backups, model
stores, runtime state and credentials. Ignored/private working-tree files were
neither opened nor copied and are outside the tracked-file exclusion counts.
